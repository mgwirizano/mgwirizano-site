# Mgwirizano member portal

Mobile-friendly member and administrator portal, with a no-new-subscription deployment path.

## Status

The interactive preview uses **fictional records only**. It does not authenticate real members, send email, read the live spreadsheet or change existing payment records.

The Apps Script backend and email/password authentication integration are implemented, but have **not been deployed or tested against the organization's Firebase project or live records**. Production activation requires the setup and reconciliation in [SETUP.md](SETUP.md).

## Included

- Member overview, contribution ledger, available credit, historical payment records, CSV export.
- Email/password activation, verification, sign-in, token refresh and password reset through Firebase Authentication REST endpoints.
- Server-side token validation and exact verified-email-to-Member-ID linking. Suspended and removed members are blocked.
- Administrator member accounts, access suspension/restoration and reset-email requests.
- Integer-cent, append-only financial events; single-row atomic posting under a script lock; idempotent retries and unique bank references.
- Automatic excess-payment credit; optional automatic credit allocation when a new obligation is created.
- Reversals and recorded refunds. No money is transferred by this software.
- Private PDF delivery from an approved Drive folder, with role checks and access logging.
- Member announcements, read acknowledgement, enquiries and administrator replies.
- Optional authenticated payment bridge. It is disabled by default and must be connected to the current payment scanner after review.

## Files

- `dist/`: independent, clearly labeled interactive preview. Safe to publish; contains no live member records.
- `apps-script/MemberPortal.gs`: standalone server and API.
- `apps-script/MemberPortal.html`: bundled production interface; generated by `node build.mjs`.
- `apps-script/Ledger.gs`: shared ledger module generated from `ledger.js`.
- `apps-script/PaymentBridge.gs.example`: integration helper for the existing scanner project, not automatically installed.
- `github-members/`: small GitHub Pages entry page pointing to the separate secure Apps Script portal once configured.
- `tests/`: finance and security unit tests.

Run `node --test tests/*.test.cjs` and `node build.mjs` after edits. No package installation is needed.

## Scope limits

This release does not recalculate constitutional benefit eligibility, update existing TRACK balances, infer old unused credits, automatically enroll new members, issue refunds through a bank, or change the existing site's authentication endpoints. Existing scripts remain authoritative until an explicit, reconciled cutover. Legacy credit fields are not blindly added together.

All configured administrators currently have the same portal privileges. Separate treasury/secretary roles, approval workflows, document version withdrawal, full enquiry-thread history and automatic obligation creation from new FUNDS rows are follow-up work. Do not interpret an account marked ACTIVE as benefit eligibility.

No Firebase Cloud Storage, paid Cloud Functions, SMS authentication or billing account is required. Existing Google storage and Apps Script quotas apply. The GitHub site stays hosted where it is.
